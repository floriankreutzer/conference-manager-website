# Meeting workflow icons

Six original line icons created for the approved Pavurel website direction: request,
participants, room/equipment, catering, changes and coordination.

The icons use 24 × 24 view boxes with consistent line weight and restrained Bordeaux
accents. They accompany visible text and are decorative in the website markup.
They are not adaptations of the corporate signet and do not imply product availability.
The owner approved their use with the website design on 19 October 2026.

## Shared family and source ownership

These six files remain the website's original rendered workflow icons. For new or
changed UI icons, use the [canonical Pavurel icon contract](https://github.com/floriankreutzer/conference-manager/blob/main/docs/ICON-SYSTEM.md)
and its versioned sources in the product repository's [brand assets](https://github.com/floriankreutzer/conference-manager/tree/main/assets/brand).
The shared 32-motif / 96-file working draft preserves the six original Light files;
its existence does not replace the website's current files or Astro renderer.

Record the source version and provenance when adopting a local derivative. Targeted
family migration is coordinated through [application issue #400](https://github.com/floriankreutzer/conference-manager/issues/400).
Manufacturer sign-in assets have separate guidance and are not additional Pavurel
workflow icons. Keep working archives and previews out of this public runtime directory.
